# RedSheet

PDFや問題集の上に重ねて使う、Windows用の赤シートです。矢印キーで動かし、今取り組んでいる問題の位置を示しながら、赤文字の答えを隠せます。

学生が暗記勉強で使う赤シートを、PC上で使えるソフトです。

- 赤文字を背景色に近づけ、黒文字を残します。
- 隠したい文字色を画面から拾えます。背景色も変更できます。
- 周囲の画像をキャッシュし、移動中は必要な部分を切り出して表示します。
- 紹介映像に使える撮影用アプリを同梱しています。

## ダウンロードと起動

[最新版のダウンロード](https://github.com/yosi-0730/redsheet/releases/latest)からZIPを保存して展開し、`RedSheet.exe` を起動してください。インストールは不要です。

動作環境はWindows 10 バージョン2004以降、またはWindows 11と、.NET Framework 4.7.2以降です。

| ファイル | 用途 |
|---|---|
| `RedSheet.exe` | 通常の学習用 |
| `RedSheet-Recording.exe` | 録画にシートを映すための撮影用 |

## 答えを隠して問題を読む

1. PDFや問題集を開きます。
2. シートを隠したい答えの上へドラッグします。
3. シートをクリックして選択し、矢印キーで位置を調整します。

初期状態は、赤文字と白い背景を同じ薄赤へ変換する自動モードです。黒文字は黒のまま残り、灰色などは背景色に合わせた色合いになります。

赤文字が残る場合は、右クリックの「画面から隠す文字色を拾う（3秒後）」を選び、3秒以内に文字の色が濃い部分へマウスを移動してください。クリックは不要です。

`+`で隠す効果を強め、`-`で弱めます。Rキーで白い背景に切り替えると、黒・灰色・白の値を保ちながら答えを隠せます。背景色も右クリックから変更できます。

PDFをスクロールするときはPDFをクリックし、シートを動かすときはシートをクリックしてください。タスクトレイのアイコンをダブルクリックしても選択できます。

## 操作

キー操作はシートを選択した状態で受け付けます。

| 操作 | 動作 |
|---|---|
| ↑ ↓ ← → | 10pxずつ移動。長押しで連続移動 |
| Shift + 矢印 | 1pxずつ移動 |
| Ctrl + 矢印 | 50pxずつ移動 |
| C / ダブルクリック | 隠す文字色を選ぶ。半透明モードではシートの色を選ぶ |
| R | 自動モードの赤い背景と白い背景を切り替える |
| F | 自動モードと半透明シートを切り替える |
| + / - | 隠す効果を調整。半透明モードでは不透明度を調整 |
| ドラッグ | 移動 |
| シートの端をドラッグ | サイズ変更 |
| 右クリック | 設定と終了のメニュー |
| Alt + F4 | 終了 |

## 紹介映像を撮影する

[撮影用サンプルPDF](output/pdf/redsheet-demo.pdf)を用意しています。括弧内の答えだけが赤文字になっています。配布ZIPにも同梱しています。

通常版は画面キャプチャから除外されます。録画にシートを映す場合は、通常版を終了して `RedSheet-Recording.exe` を起動してください。

1. PDFの撮影したいページを表示し、シートの位置や色を合わせます。
2. シートを選択して **Ctrl + Shift + R** を押します。
3. 画面全体の画像を保持したあと、録画に映る状態へ切り替わります。
4. 録画ソフトの画面・ディスプレイのキャプチャで撮影します。
5. **Ctrl + Shift + R** をもう一度押すと通常モードへ戻ります。

撮影状態はタスクトレイの説明と右クリックメニューで確認できます。赤シート自体には録画機能はありません。

撮影中も移動・サイズ変更・色や隠す強さの調整ができます。ただし、シート内のPDF画像は固定されます。PDFをスクロールしたりページを変えたりするときは、いったん解除し、画面を更新してから入り直してください。画面から文字色を拾う操作も通常モードで行います。

## 表示と保存について

選んだ文字色に近い画像や、ほかの文字色も変化する場合があります。画面の取り込みが禁止されたコンテンツには使えません。録画への表示はキャプチャ方式によって異なる場合があります。

左右256px・上下384pxの余白をキャッシュします。移動中は端まで64px以下になるか、取得から500ms以上経過すると補充します。大きく移動してキャッシュを超えた端は、更新まで背景色で埋めます。

画面の画像はメモリ内で処理し、通常使用時に保存・送信しません。撮影用に保持した画像は、撮影モードの解除時に破棄します。

色・位置・サイズは終了時に次のファイルへ保存します。撮影状態は次回起動へ持ち越しません。

- 通常版：`%LOCALAPPDATA%/KeyboardRedSheet/settings.xml`
- 撮影用：`%LOCALAPPDATA%/KeyboardRedSheetRecording/settings.xml`

## ビルドと検証

Windowsの.NET Framework付属のC#コンパイラを使います。追加パッケージは不要です。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ./build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File ./build.ps1 -OutputName RedSheet-Recording.exe -Recording
```

実行ファイルに `--self-test` を付けると、テスト用のウィンドウを表示して移動・色変換・キャッシュを検証します。撮影用では録画への表示切替と解除後の復帰も確認します。

結果は実行したフォルダーの `self-test-result.txt` に保存します。画面の検証に失敗した場合だけ、確認用の `self-test-capture.png` を保存します。

配布ZIPは次のコマンドで生成します。両方のアプリをビルド・検証してから、実行ファイルとREADME、ライセンスだけをまとめます。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ./package.ps1 -Version 0.1.0
```
