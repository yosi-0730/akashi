# キーボードで動かせる赤シート

`RedSheet.exe` をダブルクリックして起動します。インストールは不要です。Windowsの.NET Framework 4.7.2以降で動作します。

キャッシュと赤い背景に対応した版は `RedSheet-Cached.exe` です。元の実行ファイルを残しています。使用するときは元のアプリを終了してから起動してください。

## 紹介映像の撮影用

`RedSheet-Recording.exe` は撮影用の別版です。通常版の実行ファイルは変更しません。ほかの赤シートを終了してから起動してください。

1. PDFの撮影したいページを表示し、シートの色や位置を合わせます。
2. シートをクリックして選択し、**Ctrl + Shift + R** を押します。
3. 画面全体の画像を保持してから、シートを録画に映る状態へ切り替えます。タスクトレイの説明と右クリックメニューで撮影状態を確認できます。
4. 録画ソフトの画面・ディスプレイのキャプチャで撮影します。赤シートは矢印やドラッグで移動でき、サイズ・背景色・隠す強さも調整できます。
5. **Ctrl + Shift + R** をもう一度押すと通常モードへ戻ります。

キー操作はシートを選択した状態で受け付けます。右クリックの「撮影モード」でも切り替えられます。撮影用アプリは録画そのものは行いません。

撮影中はPDFの画像を固定するため、PDFのスクロール・ページ切替はシート内へ反映されません。更新したいときは撮影モードを解除し、PDFを操作してから、もう一度撮影モードに入ってください。自分自身を繰り返し取り込むのを防ぐための動作です。色を画面から拾う操作も通常モードで行ってください。

通常モードでは録画から除外されます。撮影状態は次回起動へ持ち越しません。設定は `%LOCALAPPDATA%/KeyboardRedSheetRecording/settings.xml` に分けて保存します。保持した画面画像はメモリ内だけで使用し、撮影モード解除時に破棄します。

ビルドは `powershell -NoProfile -ExecutionPolicy Bypass -File ./build.ps1 -OutputName RedSheet-Recording.exe -Recording` です。撮影用の `--self-test` では、切替キー、実画面キャプチャへの描画、固定画像での移動、解除後の録画除外と通常更新への復帰を検証します。

PDFなどの上に赤シートを重ね、シートをクリックして選択してください。

起動時は赤いシートを表示する自動モードです。白い背景と隠したい文字色を同じ薄赤へ変換するため、シートの範囲を目印にしながら文字を隠せます。黒文字は黒のまま残り、灰色などは背景色に合わせた色合いになります。Rキーで赤い背景を消すと、従来の白い表示に戻ります。白い表示では黒・灰色・白の値を保ちます。背景色は右クリックの「シートの背景色を選ぶ」で変更できます。

静止中は約120ms、移動中は約33msの間隔で更新の必要性を確認します。色変換は操作受付とは別のスレッドで実行し、処理中の更新要求は溜めません。画面の画像は通常使用時には保存・送信しません。自動モードにはWindows 10 バージョン2004以降が必要です。

表示範囲の左右256px・上下384pxまで広く取得・変換してキャッシュします。移動中はキャッシュを切り出して表示し、端まで64px以下になるか取得から500ms以上経過したら補充します。画面外の部分は取得しません。急に大きく移動してキャッシュを超えた端は、次の変換が終わるまで背景色で埋めます。更新の速さはシートの面積やPCの負荷によって変わります。

隠したい文字の色を合わせるには、シートを右クリックし「画面から隠す文字色を拾う（3秒後）」を選び、3秒以内に隠したい文字の中央へマウスを移動します。クリックは不要です。文字の輪郭や白い背景を拾うと効果が弱くなるため、色の濃い中央を選んでください。

`-`で効き具合を下げると元の文字が徐々に戻り、`+`で上げると選んだ色が白に近づきます。黒文字は黒のまま残ります。選んだ色に近い画像やほかの文字色も変化することがあります。画面の取り込みを禁止しているPDFなどには使えません。

| 操作 | 動作 |
|---|---|
| ↑ ↓ ← → | シートを10px移動。長押しで連続移動 |
| Shift + 矢印 | 1pxずつ移動 |
| Ctrl + 矢印 | 50pxずつ移動 |
| C / ダブルクリック | カラーピッカー。自動モードでは隠す文字色、通常モードではシート色を選択 |
| F | 自動モードと半透明シートの切替 |
| R | 自動モードの赤い背景と白い背景を切替 |
| + / - | 自動モードの効き具合を5ポイントずつ調整。通常モードでは不透明度を調整 |
| シートをドラッグ | 移動 |
| シートの端をドラッグ | サイズ変更 |
| 右クリック | 色、不透明度、操作方法、終了のメニュー |
| Alt + F4 | 終了 |

シートは常に最前面に表示されます。PDFをスクロールしたいときはPDFをクリックし、シートを動かすときはシートをクリックしてください。タスクトレイのアイコンをダブルクリックしてもシートを選択できます。

終了時に色・モード・効き具合・不透明度・位置・サイズを `%LOCALAPPDATA%/KeyboardRedSheet/settings.xml` に保存し、次回起動時に復元します。

元の `../trps_0100/TRPS.exe` とは別のアプリです。重なってしまう場合は元のアプリを終了してください。

## 開発

`powershell -NoProfile -ExecutionPolicy Bypass -File ./build.ps1` でビルドします。追加パッケージやネットワーク接続は不要です。

別の実行ファイル名で生成する場合は `-OutputName RedSheet-Cached.exe` を指定します。

`RedSheet.exe --self-test` は実際のフォームに上下キーのメッセージを送り、移動量と補助キー、不透明度の処理を検証します。さらに赤と黒の検証ウィンドウをシートの下に表示し、実画面の取り込みと変換結果を確認して、`self-test-result.txt` に結果を書いて終了します。画面の検証に失敗した場合だけ、取り込み結果を `self-test-capture.png` に保存します。

色変換のスレッドを検証用に待機させ、その間も上下キーでウィンドウが移動することと、移動後に正しい位置の画像へ更新されることも確認します。

余白のキャッシュから移動先のマーカーが描画されること、期限切れと端への接近で再取得が必要になること、赤い表示で隠す文字と白い背景が同じ色になり黒は黒のまま残ることも検証します。
